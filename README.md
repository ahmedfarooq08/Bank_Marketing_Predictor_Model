# Bank Marketing Campaign Predictor

This project predicts whether a customer will subscribe to a bank term deposit using machine learning.

## Dataset
UCI Bank Marketing Dataset

## Model Used
XGBoost Classifier

## Accuracy
91%

## Project Steps
1. Importing Libraries & Dataset
2. One-Hot Encoding the Dataset
3. Splitting Dataset into Training set and Test set
4. Feature Scaling all the Columns
5. Training the XGBoost model on Featured Scaled Dataset
6. Testing the Model on the Test Set
7. Making Confusion matrix of Test Set Results
8. Determining Accuracy using K-Folds Cross Validation
9. Visualising the Results

## Technologies
- Python
- Pandas
- Scikit-learn
- XGBoost
- Matplotlib

## Results
The model achieved 91% accuracy in predicting customer subscription behavior with a Standard Deviation of 0.46%.
